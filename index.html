O que o projeto responde

  1. Como os preços de cada combustível evoluíram entre 2015 e 2024?
  2. Quais estados concentram os preços mais altos e os mais baixos?
  3. Qual combustível é o mais volátil?
  4. Qual teve a maior variação acumulada no período?

Sobre a base

Dataset simulado fornecido pelo professor, com uma observação mensal por combinação de UF e combustível entre 2015 e 2024. Para análise com dados reais, a fonte oficial é a Série Histórica da ANP. Stack: Python, pandas, matplotlib, seaborn, Streamlit.
